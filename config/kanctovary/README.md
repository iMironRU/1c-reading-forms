# Конфигурация «Канцтовары» — исходники

Учебная база серии «Чтение 1С» в формате выгрузки конфигурации в XML-файлы.
Состав и решения, по которым он собран, — в `docs/konfiguraciya.md`; откуда
взялись решения — в `docs/sverka-kanctovary.md`.

Режим совместимости — 8.3.27. Форм, подсистем и данных здесь нет нарочно:
формы читатель создаёт по ходу книги о формах, а данные загружаются отдельно.

## Что внутри

```
src/
├── Configuration.xml
├── Catalogs/              ЕдиницыИзмерения, Товары, Контрагенты, Склады
├── Documents/             ПоступлениеТоваров, РеализацияТоваров,
│                          ПриказОбИзмененииЦен (проведение в модулях)
├── InformationRegisters/  ЦеныТоваров
├── AccumulationRegisters/ ТоварыНаСкладах, Продажи
└── Reports/               ОстаткиТоваровНаСкладе (СКД)
```

Исходники прошли структурную проверку: конфигурация и все одиннадцать объектов
без ошибок, схема отчёта без ошибок.

## Почему нет готового .cf

Собрать `.cf` на машине, где писалась книга, не вышло: платформа 8.3.27 там
стоит, но без лицензии, и загрузка исходников останавливается сообщением «Не
найдена лицензия». Файл собирается на стенде в одно действие.

## Как собрать на стенде

**Через Конфигуратор.**

1. Создайте пустую информационную базу и откройте её в Конфигураторе.
2. «Конфигурация» → «Загрузить конфигурацию из файлов…», укажите каталог `src`.
3. Обновите конфигурацию базы данных.
4. «Конфигурация» → «Сохранить конфигурацию в файл…» → `Kanctovary.cf`.

**Командной строкой** — то же самое без окон:

```bash
1cv8 CREATEINFOBASE File="C:\Stand\Kanctovary"
1cv8 DESIGNER /F"C:\Stand\Kanctovary" /LoadConfigFromFiles "src" /UpdateDBCfg
1cv8 DESIGNER /F"C:\Stand\Kanctovary" /DumpCfg "Kanctovary.cf"
```

## Что проверить после загрузки

- Все одиннадцать объектов на месте, в дереве нет форм.
- Поступление проводится и приходует остатки; реализация проводится, списывает
  остатки и пишет продажи; приказ об изменении цен пишет цены.
- Отчёт «Остатки товаров на складе» открывается и группирует по товару и складу.

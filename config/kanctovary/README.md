# Конфигурация «Канцтовары» — исходники

Учебная база серии «Чтение 1С» в формате выгрузки конфигурации в XML-файлы.
Состав и решения, по которым он собран, — в `docs/konfiguraciya.md`; откуда
взялись решения — в `docs/sverka-kanctovary.md`.

Режим совместимости — 8.3.27. Форм и подсистем здесь нет нарочно: их
читатель создаёт по ходу книги о формах.

## Что внутри

```
src/
├── Configuration.xml
├── Catalogs/              ЕдиницыИзмерения, Товары, Контрагенты, Склады
├── Documents/             ПоступлениеТоваров, РеализацияТоваров,
│                          ПриказОбИзмененииЦен (проведение в модулях)
├── InformationRegisters/  ЦеныТоваров
├── AccumulationRegisters/ ТоварыНаСкладах, Продажи
└── Reports/               ОстаткиТоваровНаСкладе (СКД)
```

Исходники прошли структурную проверку: конфигурация и все одиннадцать объектов
без ошибок, схема отчёта без ошибок.

## Готовые файлы

| файл | что это |
|---|---|
| `build/Kanctovary.cf` | конфигурация без данных — для тех, кто собирает базу сам по «Дереву метаданных» |
| `build/Kanctovary.dt` | база с данными — та самая, на которую опираются примеры серии |

Данные в `.dt` — те же, что у песочницы запросов (`1c-reading-queries/assets/sandbox`):
не копия, а результат загрузки из тех же YAML-файлов. Документы в базе
проведены самой 1С, и записи регистров, которые она при этом написала,
совпадают с записями песочницы до строки.

## Синхронность с песочницей

Источник данных серии один — `kanctovary.data.yaml` книги о запросах.

| инструмент | что делает |
|---|---|
| `tools/check-sync.py` | без 1С: состав песочницы против исходников конфигурации; записи регистров против проведения документов |
| `tools/make-loader.py` | из данных песочницы генерирует код загрузки для 1С |
| `tools/check-base.py` | сверяет то, что записала 1С, с данными песочницы |
| `tools/build-base.sh` | всё вместе: проверка, `.cf`, временная база с загрузчиком, загрузка и проведение, сверка, чистая конфигурация, `.dt` |

Загрузчик живёт только во временной копии исходников: в `.cf` и `.dt` его нет
— после загрузки базе возвращается чистая конфигурация.

```bash
python3 config/kanctovary/tools/check-sync.py   # быстро, после любой правки
bash    config/kanctovary/tools/build-base.sh   # полностью, нужна 1С с лицензией
```

Во время загрузки на экране на несколько секунд появляется окно 1С — оно
закрывается само.

## Как собрать самому

**Через Конфигуратор.**

1. Создайте пустую информационную базу и откройте её в Конфигураторе.
2. «Конфигурация» → «Загрузить конфигурацию из файлов…», укажите каталог `src`.
3. Обновите конфигурацию базы данных.
4. «Конфигурация» → «Сохранить конфигурацию в файл…» → `Kanctovary.cf`.

**Командной строкой** — то же самое без окон:

```bash
1cv8 CREATEINFOBASE File="C:\Stand\Kanctovary"
1cv8 DESIGNER /F"C:\Stand\Kanctovary" /LoadConfigFromFiles "src" /UpdateDBCfg
1cv8 DESIGNER /F"C:\Stand\Kanctovary" /DumpCfg "Kanctovary.cf"
```

## Что проверить после загрузки

- Все одиннадцать объектов на месте, в дереве нет форм.
- Поступление проводится и приходует остатки; реализация проводится, списывает
  остатки и пишет продажи; приказ об изменении цен пишет цены.
- Отчёт «Остатки товаров на складе» открывается и группирует по товару и складу.
